Cowrie JSON log source

Set the absolute path to the Cowrie JSON-lines log on the SIEM server. The file must already exist and be readable by the HyShield service account. The ingestor switches immediately and begins reading the selected file; a restart is not required.

Example: /home/cowrie/cowrie/var/log/cowrie/cowrie.json

Changing this setting does not move or modify the source log. Ensure the SIEM process has read permission for the file and execute permission on every parent directory. Stop the test event generator before switching sources.
